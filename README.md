# abrak-config

فایل‌های عمومی و **امضاشده** برای اپ‌های کودک‌بان و ابرک:

| فایل | کاربرد | کلید امضا |
|---|---|---|
| `discovery.json` | آدرس سرور و پین گواهی | کلید discovery (فقط پیش مالک) |
| `updates/index.json` | فهرست نسخه‌ها و پچ‌های تفاضلی | کلید update (در GitHub Secrets ریپوی abrak) |

هر دو فایل امضای Ed25519 دارند و اپ‌ها هر فایل بدون امضای معتبر را رد می‌کنند. پس عمومی بودن این ریپو امن است. هیچ کلید خصوصی یا اطلاعات کاربر در این ریپو قرار نمی‌گیرد.

فایل APKها و پچ‌ها در بخش **Releases** همین ریپو منتشر می‌شوند.
